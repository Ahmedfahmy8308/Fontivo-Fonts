# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Fontivo and our distribution infrastructure seriously.

If you discover a security vulnerability (such as a malformed font table parser exploit, path traversal risk, or distribution tampering vector), please report it responsibly:

1. Do **NOT** open a public issue on GitHub.
2. Email the maintainers directly or use GitHub's private vulnerability reporting feature on the repository.
3. Include detailed steps to reproduce the issue and any relevant proof-of-concept files.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
